Path classification — most of the gap is an artifact

The same paired test says classification improved too. It is largely an illusion: the round-1 model is being tested in rooms it never trained in, and it loses accuracy for that reason alone. Subtracting that handicap leaves what is actually attributable to training data.

Why the discount is needed

The same round-1 model, scored on its own eval split (rooms it trained in) and on the 553 unfamiliar rooms. A drop means that model was relying on room familiarity — which inflates any comparison where only one model has it.

Three methods, different biases

No single comparison settles this, so here are all three. They disagree only where the exposure asymmetry bites — which is itself the evidence that the asymmetry, not the data, is driving the classification result.

Is the newer eval split just easier?

The control: the base model never trained on anything, so a difference in its score between the two eval splits would be pure frame difficulty. There is none — which is what licenses comparing each model on its own round's split at all.
