Picking the traversable path (classification)

Candidates are drawn on the frame; the model answers with an index. Accepted accuracy counts any candidate the dataset marks feasible, strict requires the single canonical one.

Tracing the path (regression)

Same frames, different task: predict the path to the goal as waypoints with per-point visibility. Read output format validity first — the error metrics are averaged over parseable predictions only, so a model that emits valid JSON on a handful of frames gets an error score computed from those survivors alone. Hollow markers flag exactly that: fewer than half the outputs parsed, so the value is not comparable.

Is the gap real?

Both models are scored on the same held-out frames, so the differences are paired and can be tested directly. Classification uses McNemar’s exact test on the frames where the two models disagree; regression uses a paired bootstrap 95% interval on the per-frame difference. A gap whose interval crosses zero — or whose p exceeds 0.05 — is not distinguishable from noise at this sample size.
